# Custom character style reference

`bot-style-reference.png` is the user-approved oval-visor Muse sample from
`output/slate-bot-eye-study/01-oval-visor.png`. It is bundled into the application
and sent as the visual style reference for new character previews. Additional
poses use the user-approved preview instead. Explicit non-robot descriptions
retain their subject. Originals are generated project artwork, not third-party
mascot images.
